# Court Filing Material Check

一个用于中国法院网上立案材料核对的 Codex skill。它帮助 agent 在上传材料前先判断案件类型、核对材料类别，并避免把未签字、未盖章或不符合法院要求的文件误当作正式立案材料提交。

## 适用场景

当 agent 协助处理以下事项时，可以使用这个 skill：

- 中国法院网上立案
- 一站式诉讼服务平台立案
- 民事一审、民事二审材料分类
- 起诉状、上诉状、证据材料上传前核对
- 当事人身份证明、委托手续、律师身份材料检查
- 立案补正材料复核

## 它会做什么

这个 skill 会要求 agent 在上传前先完成材料审查，而不是只根据文件名猜测用途。重点包括：

- 判断文件夹内材料更像是民事一审、民事二审，还是其他类型案件
- 匹配平台常见上传类别，例如起诉状、身份证明、委托手续、证据材料、送达地址确认书
- 检查自然人身份证明是否为身份证正反面，而不是误用普通户口本
- 检查委托手续是否齐全，包括授权委托书、所函、律师证复印件
- 确认授权委托书是否有委托人签字或捺印
- 确认所函是否为已盖章 PDF 或扫描件
- 避免把未签字、未盖章的 `.doc` 或 `.docx` 草稿当作正式材料上传
- 在最终提交前停下，并要求用户再次确认

## 核心规则

文件名相似不代表可以上传。agent 必须核对文件的法律效果：

- 需要签字或盖章的材料，应使用已签字、已盖章的 PDF、扫描件或图片
- Word 草稿不能替代正式签字、盖章材料
- 自然人身份证明通常应上传身份证正反面
- 律师代理材料通常应同时包含授权委托书、所函和律师证复印件
- 用户明确不同意调解时，agent 不应替用户选择同意调解
- 标的金额遇到平台校验时，应保留小数点后两位

## 安装方式

把整个文件夹复制到 Codex 的 skills 目录，例如：

```text
~/.codex/skills/court-filing-material-check
```

目录中应至少包含：

```text
court-filing-material-check/
  SKILL.md
  README.md
  agents/
    openai.yaml
```

如果从 GitHub 安装，其他 agent 需要能够访问该仓库。仓库是私有仓库时，需要先给对应账号或环境授权。

## 其他 agent 能否使用

可以。只要其他 agent 所在环境能读取这个 skill 文件夹，或者能从 GitHub 安装这个仓库，它们就可以使用。

Codex 是否会自动调用它，主要取决于 `SKILL.md` 里的 description。当前 description 已经覆盖了中国法院网上立案、民事一审/二审、材料分类、委托手续、身份证明、补正材料核对等触发场景。

## 使用边界

这个 skill 用来做材料核对和流程提醒，不替代律师的实体法律判断。涉及是否起诉、诉讼请求如何写、证据证明力、管辖法院、诉讼策略等问题，仍应由办案人员确认。

在法院平台上，agent 可以协助填写和上传已经确认的材料，但最终提交前必须停下，让用户明确确认。
